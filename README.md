# PT 站豆瓣简介生成 · Douban Info for PT

一个 Tampermonkey（油猴）用户脚本：在 **PT 站种子详情页**左上角显示一个「豆」字入口，自动读取页面上的豆瓣 / IMDb 链接，点「生成」一键输出 PT 发种常用的 `◎片名 / ◎译名 / ◎年代 / ◎产地 / ◎类别 / ◎语言 / ◎首播 / ◎豆瓣链接 / ◎集数 / ◎片长 / ◎导演 / ◎编剧 / ◎主演 / ◎简介` 格式简介，复制粘贴即可用。

**一份脚本覆盖 13 个常用 PT 站**（HDWing、CHDBits、HDSky、OurBits、TTG、M-Team、HDHome、PTer、KeepFRDS、SpringSunday、Audiences、EastGame、HHanClub），界面会采样各站顶栏主色自动换色，深色站自动切深色毛玻璃。

不自动请求、不后台抓取，只在点「生成」时才访问豆瓣。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）；
2. 下载本仓库的 [`douban-pt-uploader.user.js`](./douban-pt-uploader.user.js)，拖入浏览器；
   或复制其全部内容，在 Tampermonkey「管理面板 → ➕ 新建脚本」里粘贴后保存（Ctrl+S）；
3. 打开任意受支持站点的种子详情页（多为 `details.php?id=xxx`，TTG 为 `/t/数字/`），页面左上角出现「豆」字入口即安装成功；
4. **首次点「生成」时 Tampermonkey 会弹出跨域授权**（访问 `m.douban.com` 等），请选「**总是允许此域名**」，否则抓不到数据；IMDb 兜底会请求 `v3.sg.media-imdb.com`、`v3-cinemeta.strem.io`，每周更新检查会请求 `raw.githubusercontent.com`，同样允许即可。

## 使用教程

### 1. 入口与颜色状态

详情页左上角只有一个 34×34 的「豆」字小方块，**底色就是状态**。展开后的面板为**毛玻璃质感**（半透明底 + 背景模糊，透出站点内容），标题栏与输入控件同步半透明；不支持 `backdrop-filter` 的浏览器会自动退回纯色背景，保证文字清晰。

「豆」的默认底色和标题栏会**跟随当前站点主色**：脚本在页面加载时采样站点顶栏 / 菜单的颜色，取不到才用内置的站点主色兜底；深色站点会自动切成深色玻璃并加深主色，标题栏右侧显示站点名与版本号，如 `M-Team · v2.8.1`。

| 颜色 | 含义 |
|---|---|
| 灰蓝 | 页面上没有豆瓣 / IMDb 链接，需要手动粘贴 |
| 豆瓣绿 | 已自动取到链接（呼吸光晕） |
| 亮蓝 | 正在读取条目（脉冲闪烁） |
| 红色 | 失败：没取到数据 / IMDb 反查不到豆瓣 |

鼠标悬停在「豆」上自动展开面板，移开自动收起；**点过面板里的东西后会被"钉住"不自动收**（防止填到一半被收走），按 `Esc` 或点「—」收起。

### 2. 自动取链（默认开启）

打开详情页后，脚本只读页面 DOM、不发请求，自动把找到的链接填进输入框：

- 页面有豆瓣链接 → 直接填入豆瓣条目地址；
- 只有 IMDb 链接 → 填入 IMDb 地址，点「生成」时自动反查豆瓣条目；
- 都没有 → 保持灰色，自己粘贴豆瓣链接、条目 ID 或直接输片名搜索。

不想要这个行为，取消勾选「自动取链」即可。

### 3. 没有豆瓣链接也能生成（IMDb 直连）

页面上没有豆瓣链接、或暂时不想找条目时，直接在输入框里粘贴 **IMDb 影片页链接** 或 **裸 tt 号**，点「生成」即可：

- 支持的写法：`https://www.imdb.com/title/tt0111161/`、`https://m.imdb.com/title/tt0111161/?ref_=...`、`tt0111161`、`IMDb: tt0111161`；
- 脚本先取 IMDb 建议接口的片名，再用 **多个片名写法**（英文原名 / 去掉 The / Cinemeta 别名）去豆瓣搜，按 **年份 + 英文别名 + 中文名 + 影视类型** 打分；
- **命中豆瓣**（分数够高）→ 自动跳到对应条目，走完整抓取链路，输出和手填豆瓣链接完全一样，并把已知的 tt 号与 IMDb 海报带进去，不再二次匹配；
- **没命中豆瓣**（新片、译名差异大、豆瓣还没收录）→ **不再报错空白**，直接用 IMDb 数据生成一份简介：海报、片名、年代、产地、类别、上映日期、IMDb 评分、IMDb 链接、片长、导演、编剧、主演、剧情简介；同时列出豆瓣候选条目，点一个即可切换为完整豆瓣数据；
- **命中豆瓣但读取失败**（未登录、条目页被安全验证拦截、条目被删）→ 也会自动退回 IMDb 数据生成，不会只剩一行红字；
- 兜底数据来自 IMDb 官方 suggestion 接口 + Stremio Cinemeta 公共元数据（均免 key）；豆瓣数据齐全时仍优先豆瓣。

> IMDb 兜底简介里的片名、演职员是英文名，剧情是英文；想要中文信息，粘贴豆瓣链接或点候选条目即可。

### 4. 生成

点「生成」按钮或按 `Ctrl+Enter`。生成后**鼠标移开面板会自动收起**，进度看「豆」的颜色；想再看结果把鼠标悬停回「豆」上即可。

### 5. 面板选项

| 选项 | 说明 |
|---|---|
| 模板 | 中文 ◎ 格式（默认）/ 英文 BBCode / Markdown / 纯文本 |
| 链接 | 链接渲染方式：BBCode `[url=…]` / 纯链接 / 不显示 |
| 主演 | 输出的主演条数：全部 / 15 / 10 / 5 |
| 折行 | 简介按固定字宽自动换行：不折 / 36 字 / 44 字（默认）/ 52 字。中文全角计 1、英文半角计 0.5，英文单词和链接不会被拆断 |
| 评分 | 是否输出「◎豆瓣评分 8.9/10 (xxx人评价)」 |
| 英文名 | 人名后是否跟英文（`蒋佳辰 Jiachen Jiang`） |
| IMDb | 是否输出「◎IMDb」行（自动匹配，详见下文） |
| 海报 | 海报图来源：自动（优先 IMDb）/ 仅 IMDb / 仅豆瓣 / 不显示 |
| IMDb 补号 | 手动填 `tt1234567`，匹配失败时用 |
| 编剧补全 | 豆瓣接口编剧不全时，手动补 `徐頔 Di Xu / 孔二狗 Ergou Kong` |

### 6. 复制与粘贴

底部两个按钮：

- **复制简介**：复制预览全文，成功后自动收起，「豆」变绿；
- **打开豆瓣**：新标签打开对应条目（遇到安全验证时先在这里通过，再回来重新生成）。

预览框本身可以直接编辑，改完再复制。

### 7. 版本号与自动更新检测

- **版本号**：面板标题栏右侧显示 `HDWinG · v2.5.0`，底部虚线下方也有版本行；
- **每周自动检查**：脚本每 7 天拉取一次本仓库的脚本头部 `@version` 与本地版本比对（不发多余请求）；
- **新版本红点**：发现新版本时，「豆」图标右上角出现**闪烁红点**，展开面板后底部有红色「发现新版本 vX.Y.Z → 点击安装更新」入口，点它会打开最新脚本页，Tampermonkey 会自动弹出安装 / 更新界面；
- **手动检查**：点面板底部的版本行可以立即检查一次；
- 脚本头部同时声明了 `@updateURL / @downloadURL`，Tampermonkey 自带的「重新检查更新」也能直接命中本仓库。

## 数据从哪来（为什么有些字段不全）

脚本使用豆瓣公开接口组合抓取，按优先级逐层补全：

| 来源 | 提供内容 | 限制 |
|---|---|---|
| `rexxar` 主接口 | 标题 / 又名 / 年代 / 产地 / 类别 / 语言 / 首播 / 集数 / 片长 / 简介 / 评分 | 无 |
| v2 API | 备用主数据 | 同上 |
| H5 详情页 | 编剧 / 集数 / 首播 / 每集片长 / 播出平台 | 无 |
| `credits` 接口 | 演职员 + 英文名 | 固定只返回 8 条 |
| `celebrities` 接口 | 演职员 + 英文名（与 credits 合并去重） | 演员为主 |
| 条目页（登录态） | **完整编剧** / IMDb 号 | 未登录或被安全验证拦截时拿不到 |
| IMDb suggestion | IMDb 号反查片名 / 年份 / 海报 | 模糊搜索，需按 id 精确筛选 |
| Stremio Cinemeta | IMDb 号直取剧情 / 导演 / 编剧 / 演员 / 类型 / 片长 / 评分 | 免 key；仅 IMDb 兜底时用 |

已知边界：

- **编剧**：公开接口最多给到 2–3 人，完整名单只有登录后的条目页才有。脚本会尝试抓取登录态页面，抓不到时用「编剧补全」框手动补一次即可；
- **评分 / IMDb**：条目太新（如 2026 待播剧）豆瓣可能还没开评分、没关联 IMDb，这是数据源本身没有，不是脚本问题；
- **海报**：豆瓣图床有 Referer 防盗链，站点带 `no-referrer` 时会 418 显示不出来，所以默认用 IMDb 图（无此限制）。

## 常见问题

**Q：编辑种子页（edit.php）会不会弹出来？**
不会。脚本只在 `details.php?id=数字` 且不带 `edit / takeedit / mod` 等参数的页面注入，编辑页、上传页、评论页全部静默。

**Q：提示「没拿到数据」？**
先点「打开豆瓣」，在浏览器里登录并通过安全验证，回来重新点「生成」。

**Q：页面没豆瓣链接，只有 IMDb 链接怎么办？**
直接把 IMDb 影片页链接粘进输入框点「生成」。会先反查豆瓣，反查不到也会用 IMDb 数据生成一份简介，详见「3. 没有豆瓣链接也能生成」。

**Q：图标被站内公告条挡住？**
脚本会自动检测固定 / 吸顶元素并逐档下移避让；仍被挡时可手动拖动面板。

**Q：想用在没列出来的站？**
在脚本头部加一行 `// @match *://*.域名/*`，再往 `SITES` 登记表里加一条 `{ k: '短标识', n: '站名', h: ['域名'], a: '#主色' }` 即可（主色只是兜底，运行时会优先采样站点真实顶栏色）。标准 NexusPHP 站（`details.php?id=`）不用改详情页规则；URL 结构特殊的站补一条 `d: [/正则/]`，id 在路径里的加 `pathId: true`。
